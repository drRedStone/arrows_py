в меню:
    f1 - менять тему(не советую, всратая реализация)
    серая кнопка - создать новую карту
    зеленая - запустить соотв карту
    красная - удалить
    желтая - переименовать, ввод только на русском, корректно работает с английской раскладкой
    оранжевая(не кнопка) - индикатор ввода, нужно нажать enter, чтобы закончить ввод

    список можно листать колесиком мыши
    
в игре:
    esc - выйти(и сохранить)
    f1 - поменять тему
    w a s d - направить стрелку
    f - отразить ее
    q - взять стрелку с поля, можно взять ничего, чтобы освободить курсор
    r - удалить с поля стрелку под курсором

    e - выделить область поля
    shift + e - множественное выделение (пока часть поля выделена, нажимаешь шифт и е, чтобы выделить другую часть поля, не сняв первое выделение)
    с - копировать
    x - вырезать
    v - вставить

    плюс/минус(клавиши после нуля) - изменить скорость симуляции

    на экране табличка со стрелочками, стрелочку можно выбрать цифрами

    переключать табличку:
    tab + 1 - красные стрелки
    tab + 2 - синие стрелки
    tab + 3 - желтые стрелки

    пробел - переключение паузы

    ПКМ - активация стрелочки-кнопки или установка выбранной стрелочки на поле
    вращать колесико мышки - менять масштаб
    нажимать колесико мыши и двигать мышь - двигать поле

в SET проверить параметры
запускать test_main
